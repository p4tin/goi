## Bugs found by acceptance and fixed

1. **Runs started before the Run/Debug window was first opened got no tab.** The windows subscribed to events only when their panel first rendered. They now subscribe at install time and attach their DOM when the panel renders.
2. **Clicking a line number didn't set a breakpoint.** CodeMirror's `domEventHandlers` only listen on the content DOM, not the gutters. The listener now sits on the editor root, with a regression test.
3. **Show Difference included `TestGreeting` in the actual value.** The testify parser dropped row labels, so the `Test:` row didn't end the value block.
4. **Delve build errors read "Check the debug console".** Launch errors now include the build output (`DrainEvents` waits for events queued before the response).
5. **Debug sessions never ended.** Delve keeps the connection open after `terminated`, so the client now disconnects.
6. **Debugging failed on symlinked project paths.** On macOS `/var` → `/private/var`, Go reports the program as "outside main module". `program`/`cwd` are now resolved, and frame and breakpoint paths are mapped back.
7. **Concurrent PTY close was a data race.** go-pty's `Close` isn't safe to call twice concurrently, so it's now wrapped in `sync.Once`.

## Not verified

- **Windows and Linux runs.** Code cross-compiles; ConPTY and `taskkill` paths are untested here. CI runs the Go and TS tests on both.
- **Clicking through the native window (WKWebView).** Everything was driven through the browser-mode harness.
- **Configurations dialog UI, Shell/Makefile configurations, before-launch tasks in the UI.** Backend and unit tests only.
- **Test results of earlier runs after a frontend reload.** Tabs are restored without results, because events aren't replayed.
