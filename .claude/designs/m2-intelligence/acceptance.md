# M2 — Acceptance & Performance Results

Date: 2026-11-07 · Host: macOS (arm64), Go 1.26.10, Wails 2.17.1, gopls v0.24.0
Method:
- unit and integration tests: `go test ./internal/...` (race-checked for lsp, gopls, rpc, textsearch) and `npm test` (318 tests);
- the real-gopls integration test (`TestRealGopls`);
- the opt-in latency test (`GOI_GOPLS_BENCH=1`);
- headless Chrome over CDP against `wails dev` (real backend, real gopls), using `tools/e2e/m2.json` on the module generated by `tools/e2e/m2-sample.sh`.

To reproduce the E2E run:
```
tools/e2e/m2-sample.sh /tmp/goi-m2-sample
GOI_HOME=/tmp/goi-m2-home wails dev -appargs "--project /tmp/goi-m2-sample"   # keep stdin open
node tools/e2e/cdp.mjs tools/e2e/m2.json
```
